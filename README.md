# Tversky-attn
Notebooks run for Tversky wrapper for RNNs. The notebooks have the implementation wrapper for both xLSTM and ViL

Based on based on the paper: [Tversky Neural Networks: Psychologically Plausible Deep Learning with Differentiable Tversky Similarity](https://arxiv.org/abs/2506.11035), which adds this similarity measure to Linear Layers. This project adds a simliar branch to RNNs and benchmarks them on different models and datasets
